# メール領収書 → MF経費 自動アップロード

Gmail の領収書メールから添付ファイル（PDF/画像）を Google Drive に自動保存し、
MF経費の Google Drive 連携で自動取込させるスクリプト。

## セットアップ手順

### 1. Google Drive にフォルダ作成
- 「MF経費_領収書」などの名前でフォルダを作成
- フォルダIDをコピー（URLの `folders/` 以降の文字列）

### 2. GAS プロジェクト作成
- https://script.google.com で新規プロジェクト作成
- `Code.gs` の内容を貼り付け
- スクリプトプロパティに `DRIVE_FOLDER_ID` を設定
  - 歯車アイコン > スクリプトプロパティ > `DRIVE_FOLDER_ID` = フォルダID

### 3. テスト実行
- `testRun` を実行して動作確認
- 初回は Gmail / Drive へのアクセス許可が求められる

### 4. トリガー設定
- `setupTrigger` を1回実行 → 毎日9:00に自動実行される

### 5. MF経費側の設定
- マネーフォワード クラウド経費 > 管理設定 > Google Drive連携
- 手順1で作成したフォルダを監視対象に設定

## 送信元の追加

`Code.gs` の `SENDER_DOMAINS` 配列に送信元ドメインを追加すればOK。
`SUBJECT_KEYWORDS` に件名キーワードを追加することもできる。

## 処理済みメールの管理

- 処理済みメールには `MF経費_処理済み` ラベルが自動付与される
- 再処理したい場合はラベルを外せばOK
